# Japanese Wikipedia proper-noun attribution

`data/nouns/nouns-term-bank-1.json` is a compact CJ2R runtime adaptation of Japanese Wikipedia proper-noun statistics and readings.

The project historically received this information through the Anki shared deck **Japanese Proper Nouns** (legacy shared-deck ID `3885156604`). The deck description states that its statistical and pronunciation information was pulled from Japanese Wikipedia. During the 2026-09-06 provenance cleanup, CJ2R removed the imported Anki/Yomitan card formatting and glossary strings. The retained file contains only the surface form, reading candidates, coarse name categories, relative reading weights and rank needed by the resolver.
