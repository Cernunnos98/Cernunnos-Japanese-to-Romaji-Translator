# Japanese Language Data attribution

The translator uses **Japanese Language Data** by jkindrix as an open reference/derivation source for reviewed reading validation and conjugation-class coverage.

Project: https://github.com/jkindrix/japanese-language-data
Version reviewed: 0.9.0, generated 2026-04-14
Licence: CC BY-SA 4.0
JMdict data: Electronic Dictionary Research and Development Group (EDRDG), subject to the EDRDG licence terms.

The translator does not ship the repository's full datasets. It keeps only small reviewed data needed by the runtime; the conjugation integration is represented by a compact configuration rather than the multi-megabyte generated conjugation table.
