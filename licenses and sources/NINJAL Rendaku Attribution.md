# NINJAL Rendaku source attribution

The translator's `data/rendaku/rendaku-evidence.json` file contains a small set of manually reviewed examples derived from the National Institute for Japanese Language and Linguistics (NINJAL) project *The Japanese Lexicon: A Rendaku Encyclopedia*.

Source pages:

- NINJAL Rendaku databases: https://www2.ninjal.ac.jp/past-projects/rendaku/en/database/
- N+V=N Rendaku Database Commentary: https://www2.ninjal.ac.jp/past-projects/rendaku/Description.pdf

The project does not redistribute the full NINJAL database. The current evidence file contains only the specifically reviewed complete-word readings used by the translator and its QA. Rendaku remains evidence-driven: these examples are not used as a basis for blindly predicting unseen compounds.
