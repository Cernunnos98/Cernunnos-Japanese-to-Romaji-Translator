# MJ Character Information Attribution

CJ2R includes a compact, transformed Japanese-use Han scope bank derived from factual fields in the **MJ文字情報一覧表 (MJ Character Information List) Ver.006.02**.

The MJ文字情報一覧表 is provided by the 文字情報技術促進協議会 under the **Creative Commons Attribution-ShareAlike 2.1 Japan (CC BY-SA 2.1 JP)** licence. The provider requests that use identify IPA as the copyright source.

Source: https://moji.or.jp/mojikiban/mjlist/

CJ2R does not redistribute the complete MJ workbook. The derived bank retains only the minimal character, reduction, Japanese-reading and source-identifier facts required for Japanese-scope classification and reading-candidate provenance.

Unicode Unihan 18.0.0 Japanese-specific properties are used only as a secondary cross-check. Unicode attribution remains covered by `Unicode Data Attribution.md`.
